# Algorithms and Programming Fundamentals

## Overview

This repository contains laboratory work completed over 2 terms studying algorithms and programming fundamentals. The project demonstrates progression from basic C++ concepts to advanced data structures and algorithms.

## Project Structure

### Term 1: Foundation (Labs 2-19)
- **Basic C++**: syntax, data types, operators
- **Arrays & Vectors**: one-dimensional and multi-dimensional arrays
- **Functions**: creation and usage
- **Control Structures**: loops, conditional statements
- **File I/O**: reading and writing data
- **STL Containers**: vectors, sets, maps
- **Algorithms**: search, sort, array processing

### Term 2: Advanced Topics (Labs 1-13)

#### Lab 1: File Processing
- Text file operations
- String and character processing
- Stream I/O operations
- Character frequency analysis

#### Labs 2-4: Core Algorithms
- **Sorting**: various sorting algorithms
- **Search**: linear and binary search
- **Data Validation**: input validation techniques

#### Labs 5-7: Data Structures
- **Stack**: implementation and operations
- **Queue**: implementation and applications
- **Linked List**: creation and manipulation

#### Labs 8-9: Additional Algorithms
- Recursive algorithms
- Advanced programming tasks

#### Labs 10-13: Advanced Data Structures
- **Binary Heap**: implementation and operations
- **Hash Tables**: multiple implementations
- **Algorithm Comparison**: performance analysis

## Key Achievements

1. **C++ Mastery**: syntax, data types, functions
2. **Data Structures**: arrays, vectors, stacks, queues, lists
3. **Algorithm Implementation**: sorting, searching, data processing
4. **File Operations**: reading, writing, text processing
5. **Advanced Structures**: heaps, hash tables
6. **Algorithm Analysis**: performance comparison
